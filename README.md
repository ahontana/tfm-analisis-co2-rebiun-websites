# analisis-co2-rebiun-websites
Repositorio para el análisis de sostenibilidad y rendimiento web de las páginas de bibliotecas universitarias de REBIUN. Incluye scripts para automatizar la obtención de métricas de huella de carbono y calificaciones de rendimiento

[![DOI](https://zenodo.org/badge/1183187004.svg)](https://doi.org/10.5281/zenodo.19049877)

## Guía de ejecución

Para ejecutar los scripts y reproducir los análisis realizados en el estudio, es necesario seguir los siguientes pasos:

1. **Descargar el conjunto de datos** disponible en Zenodo: [https://doi.org/10.5281/zenodo.20793123](https://doi.org/10.5281/zenodo.20793123).
2. **Renombrar el archivo descargado** como `rebiun.xlsx`.
3. **Ubicar el archivo** en el mismo directorio que los scripts.
4. **Ejecutar el script** correspondiente al análisis que se desea reproducir.

> [!IMPORTANT]
> Es necesario mantener el nombre `rebiun.xlsx` para garantizar la correcta lectura del conjunto de datos durante la ejecución de los scripts.
